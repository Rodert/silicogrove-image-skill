```text
이 Silico Grove Image Skill을 설치하고 사용해 주세요:
https://github.com/Rodert/silicogrove-image-skill

처음 사용할 때 Silico Grove API Key 입력을 먼저 요청하고 로컬 구성에 안전하게 저장해 주세요. 이후 요청에는 자동으로 재사용하고, 환경 변수를 수동으로 설정하라고 요청하지 마세요.

선택한 모델의 제공 회사에 해당하는 그룹의 API Key를 사용해 주세요. 콘솔의 그룹 이름이 고정되어 있다고 가정하지 말고, 저장된 Key에서 해당 모델을 사용할 수 있는지 확인하세요. 생성에 실패하면 제공 회사에 해당하는 Key 그룹, 모델 권한 및 잔액을 확인하도록 안내해 주세요.

공식 문서:
https://docs.silicogrove.com/zh-cn/api/#images
```
