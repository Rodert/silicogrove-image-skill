## Скопируйте для вашего ИИ

Передайте следующий запрос AI Agent, чтобы установить и использовать Silico Grove Image Skill.

```text
Установите и используйте этот Silico Grove Image Skill:
https://github.com/Rodert/silicogrove-image-skill

При первом использовании самостоятельно запросите у меня Silico Grove API Key и безопасно сохраните его в локальной конфигурации. Автоматически используйте его в следующих запросах. Не просите меня вручную настраивать переменную окружения.

Используйте асинхронные задачи изображений и скачивайте готовые изображения в мой локальный каталог вывода, а не только показывайте ссылки.

Перед каждым запросом generate или edit проверяйте обновления этого Skill в удаленном Git. Если обновления нет, продолжайте без уведомления. Если есть обновление, явно сообщите мне, что оно может содержать необходимые исправления, и обновите чистую локальную копию до запроса изображения. Если проверка или обновление не удались, либо локальные изменения блокируют обновление, сообщите мне и не выполняйте запрос; никогда не перезаписывайте локальные изменения.

Используйте API Key из группы, соответствующей поставщику выбранной модели. Не предполагайте, что название группы в консоли фиксировано; убедитесь, что модель доступна для сохраненного Key. При ошибке генерации предложите проверить группу Key поставщика, доступ к модели и баланс.

Официальная документация:
https://docs.silicogrove.com/zh-cn/api/#images
```
